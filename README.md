# Jaicodyn: More than a Hack 2027, Phase 1

Team Jaicodyn's submission to the
[More than a Hack 2027](https://github.com/metrica-sports/more-than-a-hack-2027) ball possession
challenge: label every frame of the tactical video as `H`, `A`, `D` or `X`.

Status: work in progress. No method or results yet.

## Data

The match data is licensed for the competition only and is not in this repository. Unpack the
provided bundle into `data/`, which is gitignored apart from a placeholder.

## Reproducing the submission

To be added. Running the repository with the committed weights on the provided data must
